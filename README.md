# LazyDesk AI

A local document analysis tool powered by Gemma 3 through Ollama.

## Features
- Analyze PDF, TXT and DOCX files
- Generate summaries, categories and filename suggestions
- Keep inference on your local machine

## Run
1. Install Ollama and download gemma3:1b.
2. Install dependencies: `python -m pip install -r requirements.txt`
3. Start the app: `python -m streamlit run app.py`
